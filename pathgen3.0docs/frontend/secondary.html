Understanding and representing integers

Skills S1 and S5. Learn to identify, compare, and order integers on a number line.

What is an integer?

An integer is a whole number — positive, negative, or zero. It has no fractional part and no decimal.

The number line

Zero is in the middle. Positive integers go right. Negative integers go left. Values increase as you move right.

Opposites and absolute value

Opposites are two integers the same distance from zero on opposite sides. Absolute value is that distance.
