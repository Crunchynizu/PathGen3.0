Create user

Usernames and roles are immutable after creation.

Letters, digits, and underscores. Cannot be changed later.

Admin accounts are created only via the bootstrap_admin command — never here.

The user should change this after first sign in.

Edit user

Update name and email. Username and role cannot change.

Deactivate account

The account will be locked and all active sessions invalidated.

This user will lose access immediately. History is preserved and the account can be reactivated later.

Recorded in the audit log. Visible to admins only.

Reactivate account

The account will become active again. Lifecycle fields are cleared.

Reactivation does not bypass Study Access. Students return to their previous path state and can resume from where they left off.

Delete account permanently

Only for an already-inactive, unused mistake with no protected history.

This cannot be undone. If protected history exists, the request is rejected and anonymization is offered instead.

Reset password

Set a new temporary password for this user.

The user's current password cannot be recovered. This issues a new password and signs them out of all devices.

Minimum 12 characters. Give this to the user directly — the system cannot show it again.

Recorded in the audit log. Visible to admins only.

Reset active sessions

Invalidate all sessions for this user. They must sign in again.

This does not change the password. To force a credential reset, use Reset password instead.
