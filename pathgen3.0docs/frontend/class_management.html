Create class

Give the class a code and a display name.

Uppercase letters, digits, and dashes. Immutable after creation.

Edit class

Rename the class. The code stays the same.

Assign teacher

One current teacher per class. Assigning replaces any existing teacher.

Only users with role teacher appear here.

Unassign teacher

The teacher will lose read access to this class and its students.

This teacher will be removed immediately. Historical membership is preserved.

Add students

Search and select students to add to this class.

Hold ⌘ / Ctrl to select multiple. Only currently-open memberships are affected.

Remove student

Membership is closed, never deleted. History is preserved.

Student will be removed from this class.
Removing a student never blocks learning. Class membership is for monitoring only.

Archive class

The class becomes read-only and is removed from active lists.

Archived classes are reversible. Reactivate at any time from the class list.

Recorded in the audit log. Visible to admins only.

Reactivate class

The class returns to the active list. Membership is unchanged.

Members who left while the class was archived remain closed. Add them again if needed.
