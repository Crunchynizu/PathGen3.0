Understanding and representing integers

Identify integers, opposites, and absolute value. Represent, compare, and order integers on a number line.

Skills S1 integer-identification S5 number-line

Objectives

  1. Identify integers, opposites, and absolute value.
  2. Represent, compare, and order integers on a number line.

What is an integer?

An integer is a whole number. It can be positive, negative, or zero. It has no fractional part and no decimal.

  • Integers: −8, −3, 0, 5, 12
  • Not integers: 3/4, 0.6, 12%

We use negative numbers every day. A temperature 3 degrees below zero is −3. A debt of 500 pesos is −500. A diver 6 meters under the sea is at −6.

The number line

A number line shows integers in order. Zero is in the middle. Positive integers go right. Negative integers go left.

Values increase as you move right. So −7 < −2 < 0 < 4.

Compare by position, not by digit size. −7 is smaller than −2 because it sits farther to the left.

Opposites and absolute value

Opposites are two integers the same distance from zero on different sides. −5 and 5 are opposites.

Absolute value is the distance from zero. Distance is always positive or zero. We write it with two bars.

|5| = 5 |−5| = 5 |0| = 0

Worked example

Worked example

Is −11 an integer? What is its opposite? What is |−11|?

  1. −11 has no fraction and no decimal. So it is an integer.
  2. The opposite of −11 is 11. Same distance, other side of zero. opposite(−11) = 11
  3. |−11| = 11 because −11 is 11 units from zero. |−11| = 11
Answer: −11 is an integer. Opposite: 11. Absolute value: 11.

Common mistake

Common mistake

−7 > −3 is wrong. The digit 7 is bigger, but −7 is farther left. Correct: −7 < −3.
